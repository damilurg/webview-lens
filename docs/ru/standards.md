# Соответствие стандартам ISO и RFC

`webview-lens` реализует сетевые и криптографические протоколы без внешних runtime-зависимостей и проверяет соответствие спецификациям в `test/rfc-conformance.test.ts`.

| Область                                       | Стандарты                                      | Реализация                                                                                                 | Зафиксированные требования                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сертификаты X.509 v3 (iOS MITM CA и Leaf)** | RFC 5280, RFC 5480, RFC 5758, Apple TLS Policy | `src/node/drivers/ios/certs.ts`                                                                            | Положительный 16-байтный serial; `ecdsa-with-SHA256` без `NULL` (RFC 5758); критические `BasicConstraints` и `KeyUsage` (`keyCertSign, cRLSign` для CA; `digitalSignature` для ECDSA leaf по RFC 5480 §3); `SubjectKeyIdentifier` (§4.2.1.2) и `AuthorityKeyIdentifier` (§4.2.1.1); `ExtendedKeyUsage (serverAuth)`; `SubjectAltName` (DNS + IPv4/IPv6); срок действия leaf ≤ 398 дней (365д). |
| **WebSocket-мост (iOS DevTools)**             | RFC 6455                                       | `src/node/ws-server.ts`                                                                                    | Рукопожатие `Sec-WebSocket-Accept` SHA-1 + GUID (§4.2.2); маскированные и немаскированные фреймы (7/16/64-битные длины); сборка фрагментированных сообщений `FIN=0` + `continuation` и перемежающиеся control-фреймы (§5.4); валидация control-фреймов (`FIN=1`, payload ≤ 125 байт, §5.5); коды закрытия (`1000`, `1002`, `1009`, §5.5.1 / §7.4.1).                                           |
| **QR-коды (установка iOS CA)**                | ISO/IEC 18004                                  | `src/node/qr.ts`                                                                                           | Byte mode (`0100`), версии 1–6 (до 134 байт), ECC Level L, GF(256) Reed-Solomon с межблочным чередованием (v6), finder/separator/timing/dark-module/alignment паттерны, полная оценка всех 8 масок (`0..7`) по правилам штрафов N1–N4 (§7.8.3), точные форматные биты BCH(15,5).                                                                                                               |
| **HTTP-прокси и RUM-эндпоинты**               | RFC 9110, RFC 9112                             | `src/node/override.ts`, `src/node/drivers/ios/mitm-proxy.ts`, `src/rum/server.ts`, `src/rum/aggregator.ts` | Динамическое удаление стандартных и перечисленных в `Connection` hop-by-hop заголовков (RFC 9110 §7.6.1); обязательный заголовок `Allow` на ответах `405 Method Not Allowed` (§15.5.6); потоковое ограничение тела с ответом `413`.                                                                                                                                                            |
| **Экспорт метрик RUM**                        | Prometheus Text Exposition Format 0.0.4        | `src/rum/aggregator.ts`                                                                                    | Заголовки `# HELP` / `# TYPE`, экранирование label-значений (`\\`, `\"`, `\n`), оценка перцентилей (`p50`, `p75`, `p95`) по ограниченному кольцевому буферу, `text/plain; version=0.0.4; charset=utf-8`.                                                                                                                                                                                       |
| **Web Vitals**                                | W3C Performance Timeline / Web Vitals          | `src/node/vitals-lab.ts`, `src/shared/thresholds.ts`, `src/rum/index.ts`                                   | Сессионные окна CLS (разрыв < 1 с, окно < 5 с), пороги оценок web.dev, доставка через `sendBeacon` + `fetch(..., { keepalive: true })` при закрытии WebView.                                                                                                                                                                                                                                   |
