# Standards & Protocol Conformance

`webview-lens` implements its core wire protocols with zero runtime dependencies and verifies compliance in `test/rfc-conformance.test.ts`.

| Area                                           | Standard(s)                                    | Implementation                                                                                             | Enforced Requirements                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **X.509 v3 Certificates (iOS MITM CA & Leaf)** | RFC 5280, RFC 5480, RFC 5758, Apple TLS Policy | `src/node/drivers/ios/certs.ts`                                                                            | Positive 16-byte serial; `ecdsa-with-SHA256` without NULL params (RFC 5758); critical `BasicConstraints` & `KeyUsage` (`keyCertSign, cRLSign` for CA; `digitalSignature` for ECDSA leaf per RFC 5480 §3); `SubjectKeyIdentifier` (§4.2.1.2) and `AuthorityKeyIdentifier` (§4.2.1.1); `ExtendedKeyUsage (serverAuth)`; `SubjectAltName` (DNS + IPv4/IPv6); leaf validity ≤ 398 days (365d). |
| **WebSocket Bridge (iOS DevTools)**            | RFC 6455                                       | `src/node/ws-server.ts`                                                                                    | `Sec-WebSocket-Accept` SHA-1 + GUID handshake (§4.2.2); masked & unmasked frames (7/16/64-bit lengths); multi-frame fragmented message reassembly + interleaved control frames (§5.4); control frame validation (`FIN=1`, payload ≤ 125 bytes, §5.5); Close status codes (`1000`, `1002`, `1009`, §5.5.1/§7.4.1).                                                                          |
| **QR Codes (iOS CA Onboarding)**               | ISO/IEC 18004                                  | `src/node/qr.ts`                                                                                           | Byte mode (`0100`), Versions 1–6 (up to 134 bytes), ECC Level L, GF(256) Reed-Solomon with multi-block interleaving (v6), finder/separator/timing/dark-module/alignment patterns, full 8-mask evaluation (`0..7`) with N1–N4 penalty scoring (§7.8.3), exact BCH(15,5) format bits.                                                                                                        |
| **HTTP Proxy & RUM Endpoints**                 | RFC 9110, RFC 9112                             | `src/node/override.ts`, `src/node/drivers/ios/mitm-proxy.ts`, `src/rum/server.ts`, `src/rum/aggregator.ts` | Dynamic stripping of standard and `Connection`-nominated hop-by-hop headers (RFC 9110 §7.6.1); mandatory `Allow` header on `405 Method Not Allowed` (§15.5.6); streaming body limits returning `413 Content Too Large`.                                                                                                                                                                    |
| **RUM Metrics Export**                         | Prometheus Text Exposition Format 0.0.4        | `src/rum/aggregator.ts`                                                                                    | `# HELP` / `# TYPE` headers, escaped label values (`\\`, `\"`, `\n`), bounded ring-buffer quantile estimation (`p50`, `p75`, `p95`), `text/plain; version=0.0.4; charset=utf-8`.                                                                                                                                                                                                           |
| **Web Vitals**                                 | W3C Performance Timeline / Web Vitals          | `src/node/vitals-lab.ts`, `src/shared/thresholds.ts`, `src/rum/index.ts`                                   | CLS session windows (gap < 1 s, window < 5 s), web.dev rating thresholds, `sendBeacon` + `fetch(..., { keepalive: true })` delivery on WebView unload.                                                                                                                                                                                                                                     |
